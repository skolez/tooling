# images

Tools for gathering and categorizing images.

Planned capabilities:
- Fetching images from sources (URLs, search APIs, crawlers)
- Filtering by parameters (resolution, aspect ratio, format, size)
- Categorization (tags, content, color, perceptual hashing, embeddings)
- De-duplication

Each tool should accept clear parameters and emit structured metadata
(JSON) so it can be composed with other tools or driven by an AI agent.
